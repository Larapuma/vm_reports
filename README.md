## Описание программы

Программа для анализа виртуальных машин на основе данных из CSV-файлов. Реализует систему отчетов с учетом стоимости дополнительных ресурсов.

## Структура программы

### 1. Модели данных

#### Базовые классы:
- `VM` - представляет виртуальную машину
- `Price` - представляет цены вычислительных ресурсов  
- `Volume` - представляет дополнительные HDD

### 2. Загрузчики данных

#### Классы для работы с CSV:
- `VMLoader` - загружает и управляет данными о ВМ из vms.csv
- `PriceLoader` - загружает и управляет ценами из prices.csv
- `VolumeLoader` - загружает и управляет дополнительными дисками из volumes.csv

Общий функционал загрузчиков:
- Инициализатор принимает путь к CSV-файлу
- Метод load_data формирует массив объектов соответствующих моделей
- Метод data - геттер для доступа к загруженным данным
- Обработка ошибок чтения файлов

### 3. Калькуляторы стоимости

#### `OtherHDDPriceCalculator`
- Рассчитывает стоимость дополнительных дисков для каждой ВМ
- Методы:
  - calculate_other_HDD_cost(vm_id) - вычисляет общую стоимость доп. дисков ВМ

#### `VMPriceCalculator` 
- Рассчитывает полную стоимость ВМ с учетом всех ресурсов
- Методы:
  - calculate_vm_cost(vm_id) - вычисляет общую стоимость ВМ
  - convert_to_rub - конвертирует цену из копеек в рубли

### 4. Загрузчик информации о ВМ

#### `VMInfoLoader`
- Формирует полную информацию о каждой ВМ
- Методы:
  - generate_vm_info_list - генерирует массив данных для всех ВМ
  - format_other_hhd - форматирует информацию о дополнительных дисках

### 5. Система отчетов

#### Базовый класс `BaseVMReport`
Определяет общий интерфейс для всех отчетов:
- initialize(vm_info_loader, limit) - инициализация с загрузчиком и лимитом вывода
- generate - генерация данных отчета (переопределяется в наследниках)
- get_report_name - получение названия отчета
- vm_data - доступ к данным ВМ

#### Классы-наследники:

1. `MostExpensiveVMReport` - n самых дорогих ВМ
2. `CheapestVMReport` - n самых дешевых ВМ  
3. `MostVolumeVMReport` - n самых объемных ВМ по параметру (CPU/RAM/тип диска)
4. `MostVolumeCountVMReport` - n ВМ с наибольшим количеством дополнительных дисков
5. `LargestOtherCapacityVMReport` - n ВМ с наибольшим объемом дополнительных дисков

### 6. Визуализация отчетов

#### `ReportPresenter`
- Форматирует и выводит отчеты в читаемом виде
- Методы:
  - print(report) - статический метод для вывода отчета в консоль

### 7. Менеджер отчетов

#### `ReportManager`
- Управление генерацией и отображением отчетов
- Регистрирует все доступные типы отчетов
Методы:
- show_report(report_name, limit) - основной метод для отображения отчетов
  - Поддерживает специальную команду `all` для показа всех отчетов
  - Валидирует входные параметры
  - Обрабатывает ошибки с информативными сообщениями
- available_reports - возвращает список доступных отчетов
- show_all_reports(limit) - приватный метод для отображения всех отчетов
- is_digit?(num) - проверяет корректность числового параметра

**Поддерживаемые отчеты:**
- `most_expensive` - самые дорогие ВМ
- `cheapest` - самые дешевые ВМ  
- `most_volume_cpu` - ВМ с наибольшим CPU
- `most_volume_ram` - ВМ с наибольшей RAM
- `most_volume_sas` - ВМ с наибольшим объемом SAS дисков
- `most_volume_ssd` - ВМ с наибольшим объемом SSD дисков
- `most_volume_count` - ВМ с наибольшим количеством доп. дисков
- `most_volume_count_sas` - ВМ с наибольшим количеством SAS доп. дисков
- `most_volume_count_ssd` - ВМ с наибольшим количеством SSD доп. дисков
- `most_volume_count_sata` - ВМ с наибольшим количеством SATA доп. дисков
- `largest_other_capacity` - ВМ с наибольшим объемом доп. дисков
- `largest_other_capacity_sas` - ВМ с наибольшим объемом SAS доп. дисков
- `largest_other_capacity_ssd` - ВМ с наибольшим объемом SSD доп. дисков
- `largest_other_capacity_sata` - ВМ с наибольшим объемом SATA доп. дисков



## Инструкция по запуску

### Требования:
- **Ruby 3.2.4+** ИЛИ **Docker**
- Файлы данных: vms.csv, volumes.csv, prices.csv

### Запуск:
### Способ 1: Запуск через Ruby 
```bash
# Клонирование репозитория
git clone <url-репозитория>
cd hw1

# Установка зависимостей
gem install terminal-table

# Запуск программы
ruby main.rb <название-отчёта> <число-отчётов>
```
### Способ 2: Запуск через Docker 
```bash
# Клонирование репозитория
git clone <url-репозитория>
cd hw1

# Запуск в контейнере Docker
docker run --rm -it \
  -v "$(pwd):/app" \
  -w /app \
  ruby:3.2.4 \
  bash -c "gem install terminal-table && ruby main.rb <название-отчёта> <число-отчётов>"
```
